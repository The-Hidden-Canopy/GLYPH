# Protocol artifacts

This directory is reserved for normative protocol notes, profile definitions,
and wire-format documentation. The v0.1 specification is the current source
of truth. A wire-affecting change must state whether it is backward compatible
and must identify the protocol version and vector impact.

The current resume-journal wire decision is recorded in
[ADR-0001](../adr/0001-resume-journal-glj2.md). The canonical GLJ2 completion
record vector is [glj2-completion-record-v1.hex](../../vectors/glj2-completion-record-v1.hex).
