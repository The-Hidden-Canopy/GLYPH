# Security policy

The core must fail closed on malformed manifests, impossible dimensions,
integer overflow, invalid cryptographic state, replay, unsafe paths, resource
exhaustion, and final integrity mismatch.

Do not report an unpatched vulnerability in a public issue. Use the private
coordinated-disclosure channel at `support@the-hidden-canopy.org` and include
the affected revision, platform, reproduction steps, and whether the issue is
source/unit, simulated, or hardware-observed. Do not include secrets or
private user data in the report.
